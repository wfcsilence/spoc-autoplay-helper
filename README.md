# 北师大SPOC自动刷视频助手(雨课堂)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-4.2-green)](#版本历史)
[![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge-blue)](#安装)

一个 Tampermonkey 用户脚本,为北京师范大学 SPOC 平台(雨课堂/学堂在线)提供**半自动视频学习**能力:

- ▶ 一键接管:2 倍速强制保持 + 防暂停自动恢复 + 播完自动跳下一节
- ⏸ 一键停用:回看课程时零干扰
- 智能跳节:自动跳过作业 / 图文 / 考试等非视频节点
- 手动让路:手动点进作业时脚本完全让路,写作业不被打扰

> **为什么是"半自动"?**
> 浏览器安全策略规定:页面没有真实用户点击之前,脚本调用 `video.play()` 会被拒绝(`NotAllowedError`)。合成事件无法产生用户手势,这是浏览器硬边界,任何油猴脚本都绕不过。因此设计为**每页点一次启动按钮,之后全自动**。

## 功能特性

| 功能 | 说明 |
|------|------|
| **2x 强制保持** | 播放器核心会周期性把播放速率同步回菜单档(1x)。脚本对 `video` 元素做实例级 `playbackRate` setter 拦截——播放器写任何值一律落地为 2x,它自己以为写成功了 |
| **防暂停恢复** | 检测到暂停后自动恢复(点大播放键 + 原生 `play()`),每 2.5s 一次 |
| **播完自动跳节** | 视频播完后等待顶部状态变为"已完成"(最多约 36 秒),再跳转,确保学习进度被平台记录 |
| **跳过非视频节** | 目录点选精确落点:作业 / 图文 / 考试节点自动跳过;若通过"下一单元"箭头落到非视频节,守卫逻辑会再次跳转 |
| **手动模式** | 用户手动点击目录中的作业/图文/考试时,脚本完全让路(不干预播放/倍速/跳转),回到视频节后自动恢复 |
| **回看模式** | 课程刷完后点 ⏸ 停用脚本,可正常手动回看;倍速拦截器同时放行用户自选速率 |
| **跳转冷却** | 两次目录跳转最小间隔 3 秒,防止页面未就绪时连点 |
| **实时状态面板** | 右下角面板显示当前状态:播放进度 / 已拦截改速次数 / 等待状态 / 手动模式提示 |

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展(Chrome / Edge 均可)
2. 点击 Tampermonkey 图标 → **添加新脚本**
3. 清空编辑器,粘贴 [`spoc_tampermonkey.user.js`](spoc_tampermonkey.user.js) 的全部内容,Ctrl+S 保存
4. 打开课程视频页,右下角出现 `[SPOC]` 面板即安装成功

## 使用

```
┌────────────────────────────────────┐
│ [SPOC] 2x 播放中 ✓ 325/954s        │
│ [ ▶ 已启动 ]  [ ⏸ 暂停脚本 ]      │
└────────────────────────────────────┘
```

1. 打开课程视频页
2. 点面板上的 **▶ 启动**(这一下点击同时解锁浏览器的播放权限)
3. 之后全自动:2x 播放 → 播完等"已完成" → 自动跳下一视频节(跳过作业)
4. 想回看课程 / 手动做作业:点 **⏸ 暂停脚本**,脚本完全停手;写完点目录视频节 + ▶ 启动恢复

> 💡 若启动后 `play()` 仍被拒(面板提示),在页面上再点任意位置一次即可——手势激活是页面级的,点哪里都行。

## 工作原理

```
┌─────────────────── 浏览器安全策略 ───────────────────┐
│  页面无用户手势 → video.play() 被拒(NotAllowedError) │
│  播放器核心 tick → 强制 video.playbackRate = 菜单档  │
└──────────────────────────────────────────────────────┘
                    ▲                    ▲
        ┌───────────┴────────┐ ┌─────────┴──────────┐
        │ 手势:用户点▶启动  │ │ 拦截:实例级        │
        │ (一次点击,页面级 │ │ playbackRate setter│
        │  sticky activation)│ │ 任何写入落地为 2    │
        └────────────────────┘ └────────────────────┘
```

关键技术点:

1. **`playbackRate` 实例级 setter 拦截** — `Object.defineProperty(video, 'playbackRate', { set })`,在保留原生 getter/setter 的前提下改写写入值。播放器的同步 tick 写 1x,实际落地 2x,播放器状态不感知
2. **目录树精确导航** — 解析 `.leaf-item` 列表的类型标签(`视频`/`作业`/`图文`/`考试`)与锁定状态(`icon-suoding`),目录点选代替"下一单元"箭头,实现精确落点
3. **手势激活检测** — 监听全局 `pointerdown`,解锁后脚本 `play()` 全部有效;未解锁时不调用 `play()`,避免控制台刷 `NotAllowedError`

## 已知限制

- **每页需点一次 ▶ 启动**:浏览器手势门槛是硬边界(合成事件不产生 user activation)。若你的环境允许,可用 CDP(`Input.dispatchMouseEvent` 派发真实信任事件)实现全自动,但调试端口可能被企业安全软件拦截
- 若播放器升级导致 DOM 结构变化(如 `xt-bigbutton`、`.leaf-item` 类名),选择器需同步更新

## 版本历史

### v4.2 (2026-09-28) — 当前版本

**完善性与可靠性**
- 新增**跳转冷却**(`navCooldownMs: 3000`):两次目录跳转最小间隔 3 秒,防止页面未就绪时连点
- 新增**面板消息缓存**(`lastMsg`):内容相同不重复写 DOM,消除每 1.2s 的无效渲染
- **回看模式智能解除**:回看中用户手动点播放 → 自动解除 ⏸ 标记回到接管模式(不再需要手动点 ▶)
- 元数据补全:`@author`、`@license MIT`
- 代码审查清理:移除未使用的 `pauseInterceptOn` 残留;确认无 XSS 面(setMsg 均为硬编码模板 + 数字插值)

### v4.1 (2026-09-28) — 面板双按钮

- **面板改为双按钮**:`▶ 启动`(接管)/ `⏸ 暂停脚本`(回看),解决"课程刷完后回看被抢"问题
- 新增 `enabled` 总开关:关闭时主循环仅刷新面板提示,不干预播放/倍速/跳转;`playbackRate` 拦截器同步检查开关(关闭时放行用户自选倍速)
- 新增 `pausedByUser` 标记:用户按 ⏸ 后脚本不抢恢复
- 脚本默认**未启动**,刷新页面不会再自动开始刷课

### v4.0 (2026-09-28) — 面板化重构

- **状态条改为交互面板**,启动门槛降为"点页面任意位置"(手势激活是页面级的,不必点播放键)
- 未激活前不调用 `play()`,不再刷 `NotAllowedError` 错误
- 移除 v3.x 的原型链 `pause` 拦截(在"用户手势后恢复"模型下不再必要)
- `tryStart` 简化:仅在暂停遮罩可见时点大播放键 + 原生 `play()`,消除多手段 toggle 互殴
- 面板实时显示播放进度与 2x 拦截次数
