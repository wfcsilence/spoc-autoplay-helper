# 北师大SPOC自动刷视频(雨课堂)

一款 Tampermonkey 用户脚本,为北京师范大学 SPOC 平台(雨课堂/学堂在线播放器)提供视频自动播放辅助:**2 倍速强制保持、防暂停自动恢复、播完自动跳下一视频节(跳过作业/图文/考试)、面板一键启停**。

> ⚠️ 仅供个人学习进度管理使用,请遵守学校课程规范。

## 功能特性

- **2x 强制保持**:通过实例级 `playbackRate` setter 拦截,播放器核心同步 1x 时一律落地为 2x(UI 显示什么不重要,实际速率就是 2x)
- **防暂停自动恢复**:检测到暂停后自动重启播放(点大播放键 + 原生 `play()` 双保险)
- **智能跳节**:播完等页面状态变"已完成"后,从目录精确跳转到下一个**视频**节,自动跳过作业(8)/图文(2)/考试(1)等非视频节,跳过锁定节
- **手动模式**:你手动点进作业时脚本完全让路(不抢跳、不改速),写完点回视频节自动恢复
- **一键启停**:面板两个按钮——▶ 启动接管 / ⏸ 停用回看(回看时零干扰)
- **实时状态条**:显示播放进度、拦截改速次数、等待状态等

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击 Tampermonkey 图标 → 添加新脚本
3. 粘贴 [`spoc_tampermonkey.user.js`](spoc_tampermonkey.user.js) 全部内容 → `Ctrl+S` 保存
4. 打开课程视频页,右下角出现面板

## 使用

| 步骤 | 操作 |
|------|------|
| 1 | 打开课程视频页,面板显示"未启动" |
| 2 | 点 **▶ 启动** → 脚本接管,视频自动 2x 播放 |
| 3 | 全自动运行:防暂停 + 播完跳下一视频节(跳过作业) |
| 4 | 跳到新页面后自动继续(新视频无需再点) |
| 5 | 想自己看/写作业 → 点 **⏸ 暂停脚本**,脚本完全让路 |

> **为什么需要先点一次?** 浏览器安全策略:页面无真实用户点击时,脚本调用 `play()` 会被拒绝(`NotAllowedError`)。这是无法绕过的硬边界——面板按钮的点击恰好完成手势激活,一次解决。

## 工作原理

```
用户点 ▶ 启动(手势激活)
    │
    ▼
┌─ 主循环(1.2s)────────────────────────────┐
│ 1. 非视频节(作业/图文/考试)?              │
│    ├─ 用户手动进入 → 让路,不干预           │
│    └─ 脚本落点 → 目录跳到下一视频节         │
│ 2. video 挂 2x 保持补丁(setter 拦截)       │
│ 3. 播完?→ 等"已完成" → 目录跳下一视频节    │
│ 4. 被暂停?→ 大播放键 + play() 恢复        │
│ 5. 速率偏离 2x?→ 兜底纠正                 │
└───────────────────────────────────────────┘
```

**关键技术点**:

- **playbackRate setter 拦截**:雨课堂播放器核心以固定频率把 `video.playbackRate` 强制同步回菜单档(1x),直接赋值会被覆盖。脚本在 video 实例上用 `Object.defineProperty` 重写 setter——播放器写 1x 实际落地 2x,它自己以为成功了
- **目录结构感知**:基于真实 DOM(`.leaf-item` / `.leaf-item-tag` / `.unit-tag` / `.rate-detail .text`)识别节类型与完成状态
- **手势门槛**:浏览器的 user activation 是页面级的,点页面任意位置(含面板按钮)即可解锁 `play()`

## 已知限制

- **首次启动需人工点击**:浏览器手势门槛无法用合成事件绕过,这是设计使然而非缺陷
- **企业策略环境**:若浏览器下发了禁自动播放策略,同样依赖首次手动点击
- **播放器改版**:脚本基于当前页面 DOM 结构(2026-09 实测),雨课堂改版后选择器可能需要更新

## 备用方案:Python + CDP

CDP 的 `Input.dispatchMouseEvent` 可派发真实信任事件(能过手势门槛),但需要浏览器开启调试端口。若安全软件拦截 9222 端口,需先加白名单:

```bash
python spoc_autoplay.py "https://spoc.bnu.edu.cn/ai-workspace/lms-graph/<课程ID>/video/<视频ID>"
```
